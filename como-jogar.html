Você aprende JavaScript usando código para investigar. Cada pasta traz uma história diferente, um objetivo pequeno e uma descoberta.

  1. 01 · Abra um caso

    Leia o que aconteceu e observe a pista. Os 24 casos estão disponíveis; seguir a ordem ajuda a aprender aos poucos.

  2. 02 · Investigue com comandos

    Use lerOcorrencia(); para abrir o relato e examinarObjeto("terminal"); para examinar o objeto do primeiro caso. Cada cenário informa o objeto que você pode examinar.

  3. 03 · Prepare os dados e execute

    O computador mostra os valores conforme você digita. Ao clicar em Executar programa, ele confere a solução. Com os dados corretos, a detetive anda até o objeto, faz a ação e revela uma pista no pop-up.

    const senha = "4271";
console.log(senha);
abrirPorta(senha);

    const cria uma variável; console.log mostra seu valor. abrirPorta usa a senha para agir no cenário.

  4. 04 · Compare e conclua

    Use analisarPistas(); para entender o registro recuperado e o que comparar. Consulte as fichas com conferirFicha("nome");, compare os crachás com o registro e escreva concluirCaso("nome da pessoa"); no campo de conclusão. Use o nome da ficha com o mesmo crachá do registro. Ao completar o comando correto, o caso é concluído e salvo automaticamente. O desfecho mostra a pessoa identificada, a evidência e a explicação da resposta. Você pode rever tudo no quadro do caderno.

  5. 05 · Guarde suas descobertas

    Use coletarPista(); depois de recuperar a evidência e anotar("Minha descoberta"); para criar um post-it. O caderno também guarda textos, fotos e seu quadro de pistas. A aba Cola de JavaScript reúne exemplos do que você está aprendendo.

Um passo por vez.

Você pode tentar de novo, abrir a dica ou consultar a solução. Não há cronômetro nem perda de vidas.

Os comandos de investigação são funções prontas deste jogo. Você aprende JavaScript ao chamá-las, preparar seus argumentos e resolver os desafios.

JavaScript é o foco dos casos 01 a 23. A conexão com o SQL do Supabase aparece no Caso 24.

Seu progresso e o caderno ficam neste navegador, separados pela conta. Baixe uma cópia pelo caderno para guardar as fotos e anotações ou levá-las para outro aparelho.
